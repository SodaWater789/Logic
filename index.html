How it works

  1. Task 1 splits the formula into tokens. To get prefix it reverses the tokens, swaps the brackets, makes postfix with a stack and reverses again.
  2. Task 2 reads the prefix from right to left. An atom is pushed on a stack as a leaf. A connective pops its children from the stack. The only child of ~ is kept in right so that in order prints (~p).
  3. Task 3 does in order, pre order and post order traversals. Each one is written with recursion and with a stack. In order with brackets gives back the input formula.
  4. Task 4 finds the height with recursion and with a queue that goes level by level. A single atom has height 1.
  5. Task 5 evaluates the tree bottom up. Both children are evaluated first and then the connective is applied. The truth table tries all 2k rows for k atoms.
  6. Task 6 times every task and finds the time complexity with the ratio test. See Analysis and Results.

How to run

main.cpp includes every other file so only this one file is compiled

g++ -O2 main.cpp -o logic
logic

The truth table is printed when the formula has at most 15 atoms, which is 32768 rows. A SAT 2002 file has hundreds of atoms and 2450 rows can never be printed, so for those files the program uses random truth values for the evaluation and skips the table.
